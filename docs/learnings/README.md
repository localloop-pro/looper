# docs/learnings/ — one lesson per PR, one file each

`docs/LEARNINGS.md` holds the older lessons; read both.

- One new file per PR, named `<issue>-<short-slug>.md`,
  e.g. `37-search-message-plain-text.md`.
- A few lines, issue reference first, same style as `docs/LEARNINGS.md`.
- Never append to `docs/LEARNINGS.md`: every merge to main moves its end, so
  two open PRs that both append always conflict (looper#53).
