### Shared skills registry under .SEED/skills (2026-10-03, looper#71)

- One registry for skills, plugins, MCP tools and reusable functions across
  looper, localloop.pro-main and hybridcard-v2 lives in looper at
  `.SEED/skills/`. It is documentation and routing, never access.
- Folders: the six map archetypes by their **map label** (`news, events,
  offers, stays, jobs, dining`; localloop.pro-main
  `assets/js/category-taxonomy.js`), plus registry-only `media/` and
  `platform/`. No other folders without the owner's OK; a test enforces it.
- One file per entry (looper#53), flat `key: value` frontmatter checked by
  `.SEED/skills/schema.json` (JSON Schema 2020-12,
  `additionalProperties: false`). `name` = file name, `archetype` = folder.
- The JSON index is generated by `tools/skills_index.py` and never committed.
  `backend/tests/test_skills_registry.py` runs in CI; `jsonschema` is a dev
  dependency only (production image unchanged).
- Provisional until the owner answers looper#79: `media` is registry-only,
  folder names are map labels (aliases in the README), `owner_floor` = home
  repo name, HybridCard-only archetypes go under the map archetype the user
  sees, otherwise `platform/`.
